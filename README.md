# منصة الشكاوى — إدارة الحج والعمرة، قسم الشكاوى

تستقبل شكاوى الحجاج من الجوال، ويتابعها قسم الشكاوى بالجلسات حتى الإغلاق، مع اعتراض واحد للمشتكى عليه.

| الصفحة | الرابط | لمن | الدخول |
|---|---|---|---|
| **تقديم شكوى** | `main.html` | الحاج ومرافقه | كلمة مرور عامة، أو خاصة (4 أرقام لمرة واحدة)، أو زر «تقديم شكوى مباشرة» إن فُعّل |
| **نتيجة الشكوى** | `main.html#/result` | المشتكي | رقم الشكوى + رمز المتابعة |
| **الاعتراض** | `main.html#/objection` | المشتكى عليه | رقم الشكوى + رمز الاعتراض |
| **لوحة الإدارة** | `main.html#/admin` | المدير والمسؤولون | كلمة مرور لكل شخص |
| **التقارير** | `main.html#/reports` | الإدارة العليا | كلمة مرور لكل شخص |

## 📦 دليل التسليم (لمن يستلم إدارة المنصة)

### 1. الحسابات الثلاثة (يجب أن يكون لك فيها دور «مالك»)
| الحساب | ماذا فيه | أين |
|---|---|---|
| **GitHub** — منظمة `syrian-hajj-complaints` | ملفات المنصة والموقع، وروبوت التنشيط | github.com/syrian-hajj-complaints |
| **Supabase** | قاعدة البيانات (الموسم الحالي فقط) | supabase.com/dashboard |
| **Google Drive** — مجلد «أرشيف المواسم» | ملفات المواسم السابقة وصور المرفقات | drive.google.com |

### 2. أول يوم
1. ادخل لوحة الإدارة: `https://syrian-hajj-complaints.github.io/admin.html` (وثبّتها أيقونةً على جوالك).
2. «👥 المسؤولون»: أنشئ كلمات مرور لفريقك، وأوقف كلمات من غادر.
3. رمز التصفير الخاص بك (Supabase ← SQL Editor): `select public.set_reset_code('رمز-من-8-أحرف-على-الأقل');`
4. GitHub ← المستودع ← Settings ← Secrets and variables ← Actions: تأكد من وجود السر `SUPABASE_ACCESS_TOKEN`
   (مفتاح من supabase.com/dashboard/account/tokens) ليعيد الروبوت تشغيل القاعدة إن توقفت.

### 3. العادات الدورية
| متى | ماذا | لماذا |
|---|---|---|
| **أسبوعياً** | «⚙️ الإعدادات ← 💾 التصدير» ← Excel كل الجداول، واحفظه في Drive | Supabase المجاني لا يوفّر نسخاً احتياطية للتنزيل |
| **كل شهرين** | GitHub ← Actions ← «Keep Supabase awake» ← تأكد أنه مفعّل (Enable) وشغّله (Run workflow) | GitHub يوقف الروبوت المجدول إن لم يتغيّر المستودع 60 يوماً، فتتوقف القاعدة بعد أسبوع بلا استخدام |
| **بداية كل موسم** | «🕋 الموسم» ← الموسم الجديد؛ ثم «📚 أرشفة المواسم» ← أرشفة المنتهي | القاعدة تحفظ الموسم الحالي فقط |
| **نهاية كل موسم** | إيقاف كلمات مرور المسؤولين المؤقتين، وتغيير كلمة المدير | الأمان |

### 4. قواعد لا تُكسر
- لا تُغيَّر **أسماء الأوراق ولا عناوين الأعمدة** في ملفات المواسم على Google Sheets (المنصة تقرأ الملف بها).
- ملفات المواسم والصور تبقى في مجلد مشارَك **«أي شخص لديه الرابط — عارض»**؛ والتعديل لمن أُضيف **«محرّر»** فقط.
- لا تفعّل في Google «منع العارضين من التنزيل»، وإلا لا تقرأ المنصة الملف ولا تُدمج الصور في Word.
- لا تُنشر روابط ملفات المواسم خارج الفريق (فيها أسماء وأرقام هواتف).
- لا يوضع مفتاح `service_role` في `config.js`، ولا تُستعمل كلمة المرور الافتراضية الموجودة في `schema.sql`.

### 5. إن حدثت مشكلة
| العَرَض | الحل |
|---|---|
| «تعذّر الاتصال» في كل الصفحات | القاعدة متوقفة: Supabase ← المشروع ← **Restore**، أو شغّل الروبوت من GitHub Actions |
| تعديل لا يظهر | Ctrl+F5 على الحاسوب، أو أغلق التطبيق وافتحه |
| «رمز التصفير غير صحيح» | عيّن رمزاً جديداً بالأمر في البند 2.3 |
| الرابط لا يُقبل في الأرشفة | يجب أن يكون رابط **الملف** `docs.google.com/spreadsheets/d/…` لا رابط المجلد، وبلا `rtpof=true` |
| صورة لا تُدمج في Word | الصورة غير مشارَكة «أي شخص لديه الرابط»، أو ليست صورة (PDF مثلاً) |
| زر 🎤 «غير متاح» | استعمل Chrome أو Edge، واسمح بالميكروفون |

### 6. الحدود والتكلفة
- مجانية بالكامل: GitHub Pages + Supabase المجاني (500 ميغابايت تكفي عشرات الآلاف من الشكاوى).
- عند الحاجة: خطة Supabase المدفوعة (نحو 25$ شهرياً) تلغي التوقف وتضيف نسخاً احتياطية يومية.
- تعديل الكود يحتاج مطوّراً (القسم «تعديل الكود» أدناه)، أو فتح Claude Code على هذا المجلد.

## طريقة العمل

1. **المشتكي** يملأ نموذجاً من ثلاث خطوات: بياناته وصفته وهاتفه، ثم المشتكى عليه وصفته، ثم عنوان الاعتراض ونصّه (أو يتحدث 🎤)
   ← يحصل على رقم الشكوى (مثل `1448-00001`) ورمز متابعة.
2. **المواسم**: كل موسم (1447، 1448…) يبدأ ترقيمه من 1؛ يُغيَّر من «الإعدادات». قاعدة البيانات تحفظ **الموسم الحالي فقط**
   (انظر «أرشفة المواسم» أدناه).
3. **الحالات** (سبع، تتغيّر تلقائياً حسب الجلسات):
   - جديد ← قيد المراجعة (فتح البطاقة) ← جاري المتابعة (أول جلسة) ← مغلقة (جلسة إغلاق).
   - بعد الاعتراض (مرة واحدة ضمن المهلة، 3 أيام افتراضياً): قيد مراجعة الاعتراض ← جاري متابعة الاعتراض ← مغلقة بعد الاعتراض.
   - الجلسات تُعدَّل ولا تُحذف؛ وبعد الإغلاق النهائي لا يُعدَّل إلا الجلسات.
4. **ثلاث نتائج منفصلة**: داخلية للقسم، ونص للمشتكي، ونص للمعترض (المعترض لا يرى اسم المشتكي ولا رقمه).
5. **الروابط**: حتى رابطين للشكوى (يضيفهما المشتكي أو الإدارة)، وللاعتراض (المعترض أو الإدارة)، ولكل جلسة؛ تظهر في البطاقة وملف Word وملف الموسم.
6. **المطلوب اليوم** للموسم الحالي فقط؛ الموسم السابق المفتوح للتعديل لا تظهر له تنبيهات.

## أرشفة المواسم

Supabase يحفظ الموسم الحالي فقط؛ كل موسم ينتهي يصبح ملف Google Sheets (شكاواه وجلساته وإحالاته وقراراته الإدارية)، ويُعرض داخل المنصة للجميع.
كل قرار إداري يأخذ الموسم الحالي عند إضافته.

0. **إعداد لمرة واحدة في Google Drive**: مجلد «أرشيف المواسم» مشارَك «أي شخص لديه الرابط — عارض»، وتفعيل
   «تحويل الملفات المرفوعة إلى تنسيق محرّر مستندات Google» من إعدادات Drive، وإضافة من يعدّل بدور «محرّر».
1. ابدأ الموسم الجديد: «الإعدادات ← 🕋 الموسم».
2. «الإعدادات ← 📚 أرشفة المواسم ← أرشفة موسم»: اختر الموسم المنتهي ← نزّل ملفه ← ارفعه إلى المجلد وانسخ رابطه
   ← الصقه (يُفحص تلقائياً) ← رمز التصفير ← «🗄️ أرشفة الموسم».
3. **التعديل لاحقاً أو إضافة شكاوى**: «🔓 فتح للتعديل في المنصة» (يعود الموسم إلى القاعدة) ← عدّل، أو «📋 الشكاوى» ← اختر الموسم ←
   «➕ إضافة شكوى إلى موسم …» ← ثم أعد أرشفته (ملف جديد في المجلد ورابطه، واحذف القديم). ويمكن أيضاً التعديل في ملف Google Sheets مباشرة لمن له دور «محرّر».
4. **موسم قديم** (1445 مثلاً): نزّل «القالب الفارغ»، ارفعه إلى المجلد واملأه في Google Sheets، ثم «➕ إضافة موسم سابق برابط ملفه».

- الرابط المطلوب رابط **الملف** (`https://docs.google.com/spreadsheets/d/…`)، لا رابط المجلد.
- لا تفعّل في Google خيار منع العارضين من التنزيل؛ المنصة تقرأ الملف بالطريقة نفسها.
- عند تعديل الملف يدوياً: لا تغيّر أسماء الأوراق ولا عناوين الأعمدة، فالمنصة تقرأ الملف بها.

## التقارير

أعداد الشكاوى حسب الموسم والفترة، جدول للاطلاع فقط بالأعمدة المهمة (بلا تصدير Excel؛ التصدير من لوحة الإدارة فقط)، المواسم السابقة (تُفتح داخل الصفحة للاطلاع)، وبطاقة الشكوى إن فعّلها المدير.

## التصدير

- **Word**: «دراسة شكوى» لكل شكوى (زر «📄 Word» في بطاقتها، مع صور الروابط)، و«قرار لجنة الشكاوى والصلح» (تبويب «📜 القرار»)،
  بالترويسة الرسمية؛ وتقرير المؤشرات.
- **Excel** (من لوحة الإدارة فقط): الشكاوى والجلسات والإحالات والقرارات، مقفولة للعرض فقط (ملف أرشيف الموسم غير مقفول ليُعدَّل في Google Sheets).
- **استعراض نسخة محفوظة**: فتح أي ملف Excel سابق داخل المنصة.

## التشغيل لأول مرة

1. Supabase ← **SQL Editor** ← الصق `supabase/schema.sql` كاملاً ← **Run** (غيّر كلمة مرور الأدمن في القسم الأخير قبل التنفيذ).
   لتحديث قاعدة قائمة: نفّذ الأقسام الجديدة فقط بالترتيب (آخر قسم حالياً: 52).
2. رمز التصفير: `select public.set_reset_code('رمز-من-8-أحرف');`
3. افتح `main.html#/admin`.

## تعديل الكود (للمطوّر)

- الكود في `src/app.jsx`، والصفحة تحمّل `app.js` الجاهز (أسرع على الجوال).
- بعد أي تعديل: `python build.py` ← يولّد `app.js` ويحدّث رقم النسخة في `main.html` ← ارفع الملفات.
- الإعدادات في `config.js`: الاتصال بـ Supabase، مهلة الاعتراض، مُدد التنبيهات، والقوائم الاحتياطية.
- تحديث قاعدة موجودة: نفّذ القسم الجديد وحده من `schema.sql` (الأقسام المرقّمة لا تحذف البيانات).

## التشغيل المستمر والتطبيق

- المنصة بلا تكلفة: الصفحات على GitHub Pages، والبيانات على Supabase (الخطة المجانية).
- `.github/workflows/keep-alive.yml` يزور القاعدة يومياً (9 صباحاً بتوقيت مكة) ويعيد تشغيلها إن توقفت
  (يحتاج سرّ `SUPABASE_ACCESS_TOKEN` لإعادة التشغيل التلقائي).
- قابلة للتثبيت على الجوال (زر «📲 تثبيت»)، ولها تطبيق أندرويد للوحة الإدارة (`admin.html` و`.well-known/assetlinks.json`).
- **أيقونة لوحة الإدارة**: افتح `admin.html` على الجوال ثم ثبّتها، فتفتح الأيقونة «قسم الشكاوى» اللوحة مباشرة؛
  وعلى أندرويد يعرض الضغط المطوّل على أيقونة «تقديم شكوى» اختصار «لوحة الإدارة».
- **أيقونة التقارير** للإدارة العليا: افتح `reports.html` ثم ثبّتها (أو زر «📲 تثبيت» في صفحة التقارير)، فتفتح أيقونة
  «تقارير الشكاوى» صفحة التقارير مباشرة.

## الحماية

- الموقع لا يقرأ الجداول مباشرة؛ كل عملية تمر بدالة تتحقق من كلمة المرور.
- لا يوضع مفتاح `service_role` في `config.js` إطلاقاً.
