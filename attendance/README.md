# منصة الحضور

تفقّد حضور الاجتماعات وتسجيل ملاحظاتها.
الرابط: **https://syrian-hajj-complaints.github.io/attendance/**

## طريقة الاستخدام

1. **القوائم والأسماء:** من تبويب «الأسماء» أنشئ قوائم مثل «رؤساء المجموعات» و«رؤساء التكتلات». اختر القائمة ثم استورد ملف Excel أو اكتب الأسماء يدوياً (اسم في كل سطر). المكرر داخل القائمة يُتجاهل تلقائياً. يمكن إعادة تسمية القائمة أو حذفها.
2. **بدء الاجتماع:** «بدء اجتماع جديد»، اكتب العنوان واختر القوائم المشاركة؛ يظهر في التفقّد أصحابها فقط، مقسّمين حسب القائمة.
   لتعديل اجتماع أو حذفه: زرّا ✎ و ✕ على بطاقته، أو «تعديل» و«حذف» داخل صفحته.
3. **التفقّد:** اضغط على الاسم: مرة = **✓ حاضر**، مرتين = **⏰ متأخر**، ثلاثاً = إلغاء العلامة. ومن لا علامة له يُحسب **غائباً**.
   يمكن البحث، وعرض الحاضرين أو المتأخرين أو الغائبين فقط، وعرض قائمة واحدة فقط إن شارك في الاجتماع أكثر من قائمة. يمكن التفقّد من أكثر من جهاز في الوقت نفسه.
4. **الملاحظات:** اكتب أهم ما دار في الاجتماع (`Ctrl + Enter` للإضافة)، أو اضغط **🎤 تحويل الكلام إلى نص** واختر اللهجة ثم تكلّم.
   الكلام يُضاف إلى آخر النص ولا يحذف شيئاً، ويمكن تصحيحه قبل «إضافة ملاحظة». يعمل في Google Chrome و Microsoft Edge ويحتاج إنترنت.
   يظهر عدد الكلمات أثناء الكتابة، ولكل ملاحظة، ومجموعها للاجتماع.
5. **المحضر:** «طباعة المحضر» يطبع الحضور والملاحظات، ويمكن حفظه PDF.

### العمل بدون إنترنت

- افتح المنصة **مرة واحدة والإنترنت متصل** (وسجّل الدخول) على الجهاز الذي ستستخدمه، فتُحفظ عليه الصفحة والبيانات. بعدها تُفتح بدون إنترنت.
- بدون إنترنت يعمل: فتح الاجتماعات، **التفقّد** (حاضر / متأخر)، **الملاحظات** كتابةً، وإنشاء الاجتماعات وتعديلها وحذفها.
- كل ذلك يُحفظ على الجهاز ويظهر أعلى الصفحة «📴 بدون إنترنت · N بانتظار الرفع»، ثم **يُرفع تلقائياً عند عودة الإنترنت** بوقته الفعلي.
- يحتاج إنترنت: تسجيل الدخول أول مرة، وإضافة القوائم والأسماء وتعديلها، وتحويل الكلام إلى نص.
- على الهاتف يمكن تثبيتها كتطبيق: قائمة المتصفح ← «إضافة إلى الشاشة الرئيسية».
- لا تسجّل الخروج والتعديلات بانتظار الرفع؛ تبقى على الجهاز وتُرفع بعد الدخول مجدداً من الجهاز نفسه.

### شكل ملف Excel

الأسماء في **العمود الأول** من **الورقة الأولى**، و**رابط الصورة** (اختياري) في أي عمود آخر: نصاً أو ارتباطاً تشعبياً. سطر العنوان («الاسم» أو «Name») يُتجاهل.

| الاسم | الصورة |
|---|---|
| أحمد محمد | https://drive.google.com/file/d/…/view |
| سارة علي | https://example.com/sara.jpg |

- روابط Google Drive و Dropbox تُحوَّل تلقائياً إلى صورة، ويجب أن تكون مشاركة الصورة **«أي شخص لديه الرابط»**.
- الصور المُلصقة داخل خلايا Excel نفسها لا تُقرأ؛ المطلوب **رابط** الصورة.
- إعادة استيراد ملف لأسماء موجودة تضيف صورها أو تحدّثها. ويمكن تعديل صورة أي شخص بزر 🖼 بجانب اسمه، وتكبيرها بالضغط عليها.

## قاعدة البيانات

جدول واحد اسمه `meeting_attendance` داخل مشروع Supabase الخاص بمنصة الشكاوى، ولا يمسّ جداول الشكاوى:

| kind | name | الحقول الأخرى |
|---|---|---|
| `list` | اسم القائمة | — |
| `member` | اسم الشخص | `list_id` (قائمته)، `photo_url` (صورته) |
| `meeting` | عنوان الاجتماع | `list_ids` (القوائم المشاركة)، `meeting_date`، `location`، `notes` (الملاحظات) |

خانات مقروءة في سطر كل اجتماع، **تتحدث تلقائياً** مع كل تفقّد (الأسماء مفصولة بـ «، »):

| الخانة | المحتوى |
|---|---|
| `names_all` | أسماء التفقّد: كل المطلوبين في قوائم الاجتماع |
| `names_present` | الحاضرون |
| `names_late` | المتأخرون |
| `names_absent` | الغائبون |

(وتحفظ `present` و `late` وقت تسجيل كل شخص.)

## الإعداد (مرة واحدة)

1. **إنشاء الجدول:** Supabase ← **SQL Editor** ← **New query** ← الصق [supabase/schema.sql](supabase/schema.sql) كاملاً ← **Run**.
2. **⚠️ تعطيل التسجيل الذاتي (ضروري):** **Authentication ← Sign In / Providers** ← أوقف **Allow new users to sign up**.
   بدون ذلك يستطيع أي شخص إنشاء حساب ورؤية الأسماء. منصة الشكاوى لا تستخدم هذا النظام فلا تتأثر.
3. **حساب الدخول:** **Authentication ← Users ← Add user ← Create new user**، وفعّل **Auto Confirm User**.
   للدخول باسم مستخدم مثل `admin` أنشئ الحساب ببريد `admin@attendance.local`، ثم اكتب في صفحة الدخول `admin` فقط.
   (يمكن أيضاً إنشاء الحساب ببريد حقيقي والدخول بالبريد كاملاً.) أضف حساباً لكل من يأخذ الحضور.

بيانات الاتصال في [config.js](config.js) هي نفسها بيانات منصة الشكاوى (المفتاح العام فقط).
