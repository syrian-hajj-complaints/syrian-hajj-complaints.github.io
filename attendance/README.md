# منصة الحضور

تفقّد حضور الاجتماعات وتسجيل ملاحظاتها.
الرابط: **https://syrian-hajj-complaints.github.io/attendance/**

## طريقة الاستخدام

1. **الأسماء:** من تبويب «الأسماء» استورد ملف Excel، أو اكتب الأسماء يدوياً (اسم في كل سطر). المكرر يُتجاهل تلقائياً.
2. **بدء الاجتماع:** «بدء اجتماع جديد» ثم اكتب العنوان.
3. **التفقّد:** ضع ✓ على كل من حضر (تُحفظ فوراً، وتُلغى بالضغط مرة ثانية). يمكن البحث، وعرض الحاضرين أو من لم يحضر فقط. يمكن التفقّد من أكثر من جهاز في الوقت نفسه.
4. **الملاحظات:** اكتب أهم ما دار في الاجتماع (`Ctrl + Enter` للإضافة).
5. **المحضر:** «طباعة المحضر» يطبع الحضور والملاحظات، ويمكن حفظه PDF.

### شكل ملف Excel

الأسماء في **العمود الأول** من **الورقة الأولى**. سطر العنوان («الاسم» أو «Name») يُتجاهل.

## قاعدة البيانات

جدول واحد اسمه `meeting_attendance` داخل مشروع Supabase الخاص بمنصة الشكاوى، ولا يمسّ جداول الشكاوى:

| kind | name | الحقول الأخرى |
|---|---|---|
| `member` | اسم الشخص | — |
| `meeting` | عنوان الاجتماع | `meeting_date`، `location`، `present` (من حضر)، `notes` (الملاحظات) |

## الإعداد (مرة واحدة)

1. **إنشاء الجدول:** Supabase ← **SQL Editor** ← **New query** ← الصق [supabase/schema.sql](supabase/schema.sql) كاملاً ← **Run**.
2. **⚠️ تعطيل التسجيل الذاتي (ضروري):** **Authentication ← Sign In / Providers** ← أوقف **Allow new users to sign up**.
   بدون ذلك يستطيع أي شخص إنشاء حساب ورؤية الأسماء. منصة الشكاوى لا تستخدم هذا النظام فلا تتأثر.
3. **حساب الدخول:** **Authentication ← Users ← Add user ← Create new user**، وفعّل **Auto Confirm User**.
   للدخول باسم مستخدم مثل `admin` أنشئ الحساب ببريد `admin@attendance.local`، ثم اكتب في صفحة الدخول `admin` فقط.
   (يمكن أيضاً إنشاء الحساب ببريد حقيقي والدخول بالبريد كاملاً.) أضف حساباً لكل من يأخذ الحضور.

بيانات الاتصال في [config.js](config.js) هي نفسها بيانات منصة الشكاوى (المفتاح العام فقط).
